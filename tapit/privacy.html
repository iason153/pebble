개인정보처리방침

시행일: 2026년 10월 15일

Tapit은 회원가입이 없고, 사용자가 저장한 링크를 서버로 보내지 않습니다. 저장한 내용은 사용자의 기기 안에만 있습니다.

1. 운영자

Tapit(https://pebbleitgo.com/tapit/)은 Pebble(pebbleitgo.com)이 운영하는 무료 웹 도구입니다.

2. 기기 안에만 저장하는 정보

아래 정보는 사용자의 브라우저 저장소(localStorage)에만 저장되며, 운영자에게 전송되지 않습니다.

  • 사용자가 추가한 링크 주소, 이름, 카테고리
  • 채널별 공유 기록(어느 채널로 몇 번 복사했는지)
  • Google Analytics 연동 시 불러온 채널별 방문 수 집계

브라우저 데이터를 지우거나 기기를 바꾸면 이 정보는 사라질 수 있습니다. 화면 아래 백업 기능으로 파일을 저장해 둘 수 있습니다.

3. 이용 통계

서비스 개선을 위해 Google Analytics로 방문과 버튼 사용 횟수(예: 링크 추가, 복사, 설치)를 집계합니다. 사용자가 저장한 링크의 주소나 이름은 보내지 않습니다. Google의 데이터 처리에 대해서는 Google 개인정보처리방침을 따릅니다.

4. Google Analytics 연동 (선택)

사용자가 직접 "Google 계정으로 연동"을 누른 경우에만 동작합니다.

  • 요청 권한: Google 애널리틱스 데이터 보기(읽기 전용, analytics.readonly). 데이터를 수정하거나 삭제할 수 없습니다.
  • 사용 목적: 사용자가 Tapit으로 공유한 링크에 대해, 사용자 본인의 애널리틱스에서 채널별 방문(세션) 수를 불러와 사용자 화면에 표시하는 것에만 사용합니다.
  • 처리 방식: 사용자의 브라우저가 Google에 직접 요청합니다. 운영자의 서버를 거치지 않으며, 운영자는 사용자의 애널리틱스 데이터나 접근 권한(토큰)을 받거나 보관하지 않습니다.
  • 보관: 접근 권한은 브라우저 메모리에만 잠시 있다가 화면을 닫으면 사라집니다. 불러온 방문 수 집계는 사용자의 기기에만 저장되고, "연동 해제"를 누르면 삭제됩니다.
  • 제3자 제공: Google 사용자 데이터를 다른 곳에 전송, 판매하거나 광고에 사용하지 않습니다.
  • Google 계정 설정(https://myaccount.google.com/permissions)에서 언제든 Tapit의 접근 권한을 철회할 수 있습니다.

Tapit의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

5. 개인정보 수집 여부

Tapit은 이름, 이메일, 전화번호 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.
