## 1. 왜 바꿨나 (가족 테스트 결과, 2026-10-04)

| 본 것 | 판단 |
|---|---|
| 볼일 넣기까지는 쉬운데, 카드를 눌러 세세한 설정을 하는 사람이 없음 | 숨은 설정을 없애고, 꼭 필요한 것(시간·머무는 시간)만 카드에 드러냄 |
| 진행 모드(도착·시작·끝·출발 버튼)는 다른 앱 다녀오면 흐름이 끊기고, 왜 눌러야 하는지 모름 | 버튼 누르기 삭제 → **다녀온 뒤 한 번 묻기**로 대체 |
| 구글 캘린더 시간별 알림, 근처 식당 제안, 카톡 공유는 좋아함 | 전면에 배치 |
| 갑자기 볼일이 생기면 넣어서 다시 보고 싶음 | **한 군데 더** 추가 |
| "볼일 몰린 날"만 쓰는 도구는 평소에 안 열게 됨 | **매일 쓰는 도구**로 방향 전환 |

**한 줄 정의**: 오늘·내일 일정을 넣으면 **"몇 시에 나가야 하는지"** 알려 주고, 그 시각에 알림을 받게 해 주는 도구.
**카카오내비와 다른 점**: 내비는 "운전 시간"만 안다. Getset은 집에서 차까지, 주차 자리 찾기, 엘리베이터, 접수까지 넣어서 **현관을 나서는 시각**을 알려 준다.
**주안점**: 초등학생도 설명 없이 쓸 만큼 직관적일 것 + 세세한 정확도는 그대로.

## 2. 화면 — 볼일 카드가 중심

> v1.2 초안의 "갈 곳 넣기 / 할 일 넣기" 두 버튼은 뜻이 헷갈려서 없앴다(대표 확인, 2026-10-04). 모든 것은 **볼일 카드** 하나로 통일한다.

### ① 첫 화면
- 맨 위 **[오늘] [내일] [달력]**. 기본은 오늘, 저녁 6시가 넘었고 오늘 볼일이 없으면 내일.
- 질문 한 줄: "오늘(내일) 뭐 있어요?"
- **[+ 볼일 넣기]** (큰 버튼 하나) — 한 화면에서 위에서 아래로
  1. **뭐 해요?** 진료 · 업무·미팅 · 서류·민원 · 은행 업무 · 식사·카페 · 장보기 · 픽업 · 쇼핑 · 우편·택배 · 약속·기타 (장소를 먼저 고르면 자동으로 골라짐)
  2. **어디서 해요?** 장소 찾기(이름·주소)
  3. **몇 시까지 가요?** 시각 또는 [정해진 시간 없어요]. 둘 중 하나는 꼭 골라야 함
  4. **거기서 얼마나 걸려요?** 10분~2시간 또는 [잘 모르겠어요 · 보통 ○분으로 계산]
- **[무엇이 필요해요?]** (작은 글씨: "약국·주유·현금… 주변에서 찾아 추천해 드려요") — 장소 없이 필요한 것만 있을 때. 고르면 집과 넣어 둔 볼일 근처를 찾아 **가까운 순 리스트**로 보여 주고, 사용자가 고른다(자동으로 한 곳을 정하지 않음).
- **볼일 카드**: 장소 이름 · 뭘 하는지 · 시간 버튼 · **머무는 시간 [−]40분[+]** · ✕
  - **[이 근처에서 찾기]**: 그 볼일 주변의 주차장·약국·현금·주유·택배·편의점·커피·장보기·식당을 리스트로 → 고르면 **"가기 전에 / 끝나고"** 를 묻고 그 카드에 붙임(간 김에 들를 곳)
  - 이름을 누르면 같은 화면에서 고치기. 맨 아래 "더 정확하게"에 가는 방법·주차장 종류·영업시간(v1.1의 정교한 설정)
- 아래 한 줄: "집에서 출발 · 자동차 · 끝나면 집으로 [바꾸기]", 맨 아래 **나갈 시간 보기**
- 로고(Getset): 오늘로 돌아가서 오늘 볼일 비우기(되돌리기 가능)

### ② 나갈 시간 (결과)
- 가장 크게: **"오후 12:55에 나가세요"** + "○시간 ○분 뒤"(오늘) + "오후 3:15쯤 집에 들어와요" + **"머무는 시간 모두 1시간 15분 · 2곳은 보통 값"**
- 볼일마다: **"오후 1:18에 나가요"** → "나와서 차까지 4분 + 운전 10분 + 주차·걷기·대기 9분 = 23분"(누르면 단계별로 펼쳐짐)
- 볼일마다 **머무는 시간을 글로 표시**: "여기서 1시간 머물러요" / "여기서 **보통 10분** 머무는 걸로 계산했어요 [바꾸기]" (직접 안 정한 곳은 점선으로 눈에 띄게)
- 볼일 카드 버튼: [🔎 이 근처에서 찾기] [🅿 주차장] [길찾기] [고치기]
- 상황 카드(최대 2장)
  - **식사**: 점심·저녁 시간대를 밖에서 보낼 때 → [근처 식당 보기] = 그 시간 앞·뒤 **볼일 장소 근처 식당 리스트** / [시간만 비우기] / [괜찮아요]
  - **빈 시간**: 다음 볼일까지 30분 넘게 빌 때 → [근처 카페 보기] [다른 것 찾기]
  - **주차장**: 전용 주차장이 없을 것 같은 곳 → [근처 주차장 보기]
- **근처 주차장**: 700m 안, 가까운 순. **공영 / 민영(유료)** 표시, 걸어서 몇 분. 고르면 주차장에서 걸어가는 시간까지 넣어 다시 계산.
- 맨 아래: **🔔 알림 받기** / **💬 가족에게 보내기**
- 목록 끝: "다니는 중에 볼일이 더 생겼나요?" **[볼일 더 넣기] [무엇이 필요해요?]** — 오늘이면 지난 볼일은 빼고 남은 것만 지금부터 다시 계산

### ③ 다녀온 뒤 한 번 묻기
- 첫 화면 맨 위 카드: "아까(어제) 치과, 시간 맞았어요?" → [딱 맞았어요] [일찍 도착] [늦었어요]
- 일찍/늦음 → "몇 분쯤?" → "어디서 더 걸렸어요?" (길 / 주차 / 엘리베이터·걷기 / 접수·대기 / 모르겠어요)
- [안 갔어요], [그만 묻기]. 하루 최대 3곳, 최근 3일만.

### 달력
- 달력 + 그 아래 **넣어 둔 일정 한눈에**(날짜별로 시간·이름). 누르면 그날로 이동.

## 3. 계산 규칙 (v1.1에서 더해진 것)

1. **나갈 시각 자동 결정** (`computePlan`)
   - 시간 약속(○시까지)이 있으면: 약속을 모두 지키는 **가장 늦은 출발 시각**을 5분 단위로 내림. 오늘이면 지금보다 이르지 않게.
   - 약속이 없으면: 오늘은 **지금**, 다른 날은 **오전 9시**(결과 화면에서 [나가는 시각 바꾸기]).
   - 직접 정한 시각이 있으면 그 시각.
2. **일정별 나갈 시각** = 그 일정 시작 시각 − (나와서 차까지 + 이동 + 도착 후 시간). 일찍 가서 기다리지 않고 그만큼 늦게 나감.
3. **집에서 차까지**: 출발지가 집이면 집 주차 정보(내 정보)로 "나와서 차까지·출차" 시간을 첫 운전 앞에 붙임. 돌아올 때는 "주차하고 집 안까지"를 더해 "집에 들어와요" 시각을 냄.
4. **가까우면 걷기**: 차로 다니는 날에도 직선 150m 안은 걸어가는 걸로 계산(`travel.nearWalkM`).
5. **시간만 비우기**: 장소 없는 칸. 이동·주차 없이 그 시간만 씀(엔진 `anywhere`).
6. **근처 찾기는 항상 리스트**: 기준점(집 + 넣어 둔 볼일, 또는 그 볼일 하나) 주변을 카카오 분류 검색으로 찾아 **가까운 순**으로 보여 주고 사용자가 고른다. 줄마다 "○○ 근처 · 걸어서 n분". 앱이 한 곳을 자동으로 정하지 않는다.
   - **간 김에 들를 곳**은 그 볼일 "바로 앞"(가기 전에) 또는 "바로 뒤"(끝나고)에 붙어 다니도록 순서를 고정(엔진 `prevUid`).
   - 붙은 곳끼리 직선 400m 안이면 **차를 두고 걸어서** 다녀오는 걸로 계산(`travel.chainWalkM`). 가기 전에 들르는 곳이 있어도 차는 본 볼일의 주차장에 세우는 걸로 본다.
   - **머무는 시간**: 직접 고르면 그 값(`staySet`), [잘 모르겠어요]면 보통 값(필요한 것의 값 → 내 기록 → 하는 일 종류). 결과 화면에 어느 쪽인지 항상 표시.
7. **근처 주차장을 고른 경우**: 도착 = 주차장에 주차(`lot.find`) + 걸어가기 + 건물 안, 출발 = 건물 밖 + 걸어가기 + 정산·출차(`lot.out`).
8. **직접 정한 도착 시각이 있으면** 보통 영업 "시작" 시간은 따지지 않음(끝나는 시간·쉬는 날 경고는 그대로).
9. **오늘 중간에 다시 계산**: 계산해 둔 시간표에서 끝난 시각이 지난 일정은 "다녀옴"으로 두고, 남은 일정만 지금 시각·마지막으로 다녀온 곳(위치 권한이 있으면 현재 위치)에서 다시 계산. 돌아오는 곳은 원래 출발지(집).
10. **다녀온 뒤 답 → 학습**
    - 딱 맞음: 계산했던 도착 후 시간을 기록으로 추가
    - 주차·엘리베이터·접수: 그 장소(와 장소 종류)의 도착 후 시간에 ±분
    - 길: 이동수단별 "길 보정 비율"에 반영(`Learn.addRoad`, 0.6~2배, 기록이 적을 땐 1과 섞음)
    - 모르겠어요: 반반

## 4. 알림·공유
- **알림 받기**: 캘린더 파일(.ics) 한 번에 넣기 — 일정마다 "나갈 시각"에 시작하는 일정 + **10분 전·정각 알림 2개**. 안내 3줄(받기 → 열기 → 저장). 추가로 **구글 캘린더에 하나씩 넣기** 링크.
- **가족에게 보내기**: 날짜 · 출발 시각 · 일정별 시각 · 집에 들어오는 시각을 글로 만들어 공유(카톡 등). 공유가 안 되는 브라우저는 복사.

## 7. 저장 (이 기기에만)
- 볼일: `kind`(뭘 하는지), `task`(필요한 것 종류), `near`·`nearPos`(간 김에: 붙은 볼일과 앞/뒤), `staySet`(머무는 시간을 직접 정했는지), `block`(시간만 비우기), `lot`(고른 주차장)
- 날짜별 계획: `startTime`(`auto` 또는 시각), `sched`(마지막 계산 시간표), `asked`(다녀온 뒤 답), `done`(다녀온 일정)
- 학습: `getset:learn:v1`에 길 보정(`r`) 추가
- GA4: 종류·개수·분만 보냄. 장소 이름·주소·좌표는 보내지 않음(새 이벤트: `plan_result.start_kind`, `card_action`, `need_add`, `near_add`, `lot_pick`, `visit_feedback`, `block_add`, `add_more`, `alarm_open`)

## 8. 알고 있는 한계
- **이동 시간은 아직 직선거리 어림값** — 실제 길찾기(카카오모빌리티, 서버 필요)는 가족 반응을 본 뒤. 이때 **Vercel Pro 구독 시점**을 대표에게 알릴 것.
- **주차 요금은 알 수 없음** — 공영/민영은 이름·분류로 구분한 것. 요금·운영 시간은 [지도]에서 확인.
- 알림은 앱이 직접 울리는 게 아니라 **휴대폰 캘린더**가 울림(로그인·서버 없이 가능한 방법).
- 근처 찾기·주차장 찾기는 카카오 검색을 쓰므로 인터넷이 필요. 못 찾으면 이름으로 직접 찾기로 안내.
- 근처 리스트는 **직선거리 가까운 순**이고, 그 가게가 **지금 영업 중인지는 알 수 없음**(카카오 검색이 영업시간을 주지 않음).
- 간 김에 들를 곳은 걸어서 다녀오는 걸로 어림함(차를 옮겨 세우는 경우는 따로 계산하지 않음).
- 테스트는 가짜 카카오(목)로 함. **실제 카카오 검색·아이폰 동작은 배포 후 폰에서 확인 필요.**
