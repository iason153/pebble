## 1. 한 줄 정의 (변경 없음)

**Getset(겟셋) — 뭐부터 할지, 바로 정리.**
볼일이 몰린 날, 할 일만 넣으면 **동선(순서)과 현실적인 시간표, 실제로 끝나는 시각**까지 추천해 주는 도구.

**핵심 문장**: 내비는 "도착 시간"을 알려주지만, 사람에게 필요한 건 "일이 실제로 끝나는 시간"이다.

### 1-1. 이 앱의 무기 (v1.1에서 명확히 함)

> **주차 자리 찾기, 엘리베이터 기다리기, 접수·번호표처럼 내비가 계산하지 않는 "실질 시간"을, 실제 기록으로 점점 정확하게 만든다.**

- 처음엔 **대표가 관리하는 기본값**(현장 실측으로 다듬음)으로 시작한다.
- 사용자가 쓰면서 남기는 **"도착·시작·끝·출발" 기록**으로 **개인 패턴**을 학습한다.
- 모든 사용자의 기록을 **익명으로 모아(모두의 기록)** 장소별·주차장별 값을 앱 전체에 적용한다.
- → 쓰는 사람이 늘수록 정확해지는 구조. 다른 앱이 쉽게 따라 할 수 없는 자산이 된다.

## 4. 입력 (시제품 반영 확정)

### 4-1. 날짜 (달력) — v2에서 v1으로 당김
- 메인 맨 위 "날짜" 줄 → [오늘·내일·모레] 큰 버튼 + 한 달 달력. 볼일 있는 날엔 황동색 점.
- **날짜마다 계획을 따로 저장.** 새 날짜는 출발지·끝·이동수단을 가까운 계획에서 이어받는다.
- 30일 지난 계획은 자동 정리.
- 처음 열 때 오늘 볼일이 없으면 → "다가오는 일정 있어요" 또는 "지난 볼일 오늘로 가져올까요?" 안내.
- **주말·평일 구분이 계산에 들어간다**(주차 혼잡, 영업시간·휴무).

### 4-2. 출발 시각
- 메인 표시: "오후 12:15 출발 / 지금 시각 기준 · 눌러서 바꾸기".
- 시트: 오늘이면 [지금·10분 뒤·30분 뒤·1시간 뒤], 다른 날이면 [오전 8·9·10시, 오후 1·2·3시] + **숫자 입력 [오전|오후][ 시 ][ 분 ]**.
- 24시간으로 넣어도 됨("14" → 오후 2시).

### 4-3. 볼일 추가 — 한 화면 + [추가하기]
1. 장소 검색(카카오) → 선택
2. 한 화면에서(기본값이 다 채워져 있어 바로 [추가하기]만 눌러도 됨):
   - **얼마나 있을 거예요?** [−] 20분 [+] (10분씩, 5분~10시간) + 빠른 버튼(10분·30분·1시간·1시간 30분·2시간·3시간). 장소 종류의 보통 시간 안내
   - **정해진 시간이 있나요?** 없어요 / **예약 시간**(꼭 지킴) / **원하는 시간**(최대한 맞춤) / **문 닫는 시간**(그 전에 끝냄) — 하나만 고름
   - **언제 갈까요?** 아무 때나 / 제일 먼저 / 제일 마지막
   - 가는 방법(그날 기본 따름, [바꾸기]) · **주차**(자동차일 때, 보통값 표시, [바꾸기]) · 장소 종류
   - "도착해서 볼일 시작까지 약 N분, 끝나고 출발까지 약 M분" 미리보기 (단계별 내역)

### 4-4. 집 들르기 (신규)
- 메인에 [🏠 집 들르기] 버튼 → "언제쯤·얼마나" (원하는 시간/예약 시간 그대로 사용)
- 장소 = 첫 실행에 등록한 집, 실질 시간 = 집 주차 정보로 계산
- 여러 번 넣을 수 있음. 엔진이 순서에 포함해서 계산
- **자동 제안**은 §7-4

## 5. 현실 시간 모델 (엔진의 심장 — v1.1 확장)

### 5-1. 구성
자동차로 갈 때 방문지 1곳 = **이동 + ① 자리 찾기 + ② 주차장→입구 + ③ 건물 안(접수 등) + 머무는 시간 + ④ 건물 밖으로 + ⑤ 입구→차 + ⑥ 출차**

- ①②⑤⑥은 **주차장 종류**가 정하고, ③④는 **장소 종류**가 정한다.
- 걷기·자전거·대중교통은 주차가 빠지고 ③④ + 입구까지 1분.
- **차로 와서 차로 떠날 때만** 주차장 나가는 시간이 붙는다(걸어서 들른 곳엔 차가 없음).
- 바로 옆 건물(30m 이내)로 옮기면 도착 시간을 다시 붙이지 않는다.

### 5-2. 주차장 종류 (초안 숫자, 관리 페이지에서 조절)

| 종류 | ① 자리 찾기 | ② 입구까지 | ⑥ 출차 |
|---|---|---|---|
| 야외 | 2분 | 걷기 2분 | 1분 |
| **필로티(1층)** — 신규 | 1분 | 걷기·계단 1분 | 1분 |
| 지하·건물 | 층층이 4분 | 엘리베이터 대기 2 + 탑승 1분 | 정산·출구 줄 2분 |
| **기계식** — 신규 | 입고 대기 5분 | 걷기 1분 | 출고 대기 5분 |
| 길가·공영 | 5분 | 걷기 3분 | 1분 |

### 5-3. 장소 종류 (초안 숫자)
머무는 시간 보통값 / ③ 들어갈 때 / ④ 나올 때 / 보통 주차장 / 붐비는 곳 여부 — `kinds` 표 11종(관공서·은행·병원·대형마트·동네가게·백화점·음식점·우체국·학교학원·빌딩·기타) + **집**(신규)

### 5-4. 혼잡 배수
- 주말: 대형마트·백화점·음식점 ① ×2
- 평일 점심(11:30~13:30): 음식점 ① ×1.5
- (추가) 평일 퇴근(17:00~19:00): 자동차 이동 ×1.2 — 실제 길찾기가 붙기 전까지의 임시 보정

### 5-5. 값이 정해지는 순서 (블렌딩)
한 방문지의 실질 시간은 아래 순서로 더 믿을 만한 값을 쓴다. 기록이 적을 땐 아래 값과 섞어 천천히 옮겨 간다.

```
① 내 기록 (이 장소)          ← 가장 우선. 2~3번 기록부터 반영
② 모두의 기록 (이 장소)       ← 이 장소 기록이 5건 이상일 때
③ 내 기록 (이 장소 종류)      ← "나는 병원에서 보통 오래 걸림"
④ 모두의 기록 (종류×주차장)   ← "지하 주차장 대형마트는 평균 11분"
⑤ 기본값 (관리 페이지)
```
- 섞는 방식: `추정값 = (기록수 × 기록평균 + k × 아래단계값) ÷ (기록수 + k)` — 내 기록 k=3, 모두의 기록 k=10.
- 평균 대신 **가운데값(중앙값)** 을 써서 이상하게 긴 기록(깜빡하고 끝 버튼 늦게 누름 등)에 흔들리지 않게 한다.
- 화면에는 출처 배지: "기본값" / "모두의 기록 32건" / "내 기록 4회".

## 6. 기록과 학습 — 이 앱의 무기

### 6-1. 진행 모드의 4단계 기록
각 방문지에서 **같은 자리의 큰 버튼 하나**가 순서대로 바뀐다(초등학생도 가능).

`[도착했어요]` → `[볼일 시작]` → `[다 끝났어요]` → `[출발해요]`

| 구간 | 의미 | 학습 대상 |
|---|---|---|
| 이전 출발 → 도착 | 실제 이동 시간 | 이동 어림 계수, 길찾기 보정 |
| 도착 → 볼일 시작 | **도착 후 실질 시간**(주차·엘베·접수) | ①②③ |
| 볼일 시작 → 끝 | 실제 머문 시간 | 머무는 시간 |
| 끝 → 출발 | **출발 전 실질 시간** | ④⑤⑥ |

- 중간 버튼을 건너뛰어도 된다(있는 구간만 기록). "도착"을 깜빡하면 "볼일 시작"에서 "도착은 언제쯤이었어요?(1~2분 전/5분 전/모름)" 한 번만 묻는다.
- 비정상 기록(0분, 3시간 넘는 주차 등)은 버린다.

### 6-2. 개인 학습 (기기 안)
- 장소별·장소종류별·주차장종류별 기록 → 중앙값 + 블렌딩(§5-5).
- "내 기준" 화면: "산본 이마트 주차~입구: 평균 13분 (기록 5회)" — 직접 고치기·초기화 가능.

### 6-3. 모두의 기록 (익명 수집) — v1 포함
**목표**: 모든 사용자의 기록을 모아 장소별·주차장별 값을 앱 전체에 적용.

**보내는 것 (익명, 개인을 알 수 없는 것만)**
- 카카오 **장소 ID**(공개된 가게·기관만), 장소 종류, 주차장 종류, 이동수단
- 요일 구분(평일/주말), 시간대(2시간 단위)
- 구간 시간(분): 도착 후, 머문 시간, 출발 전, 실제 이동/어림 이동 비율

**절대 안 보내는 것**
- 집·현재 위치·자주 가는 곳(회사 등) 기록, 좌표, 주소, 사용자 이름·연락처, 기기 고유번호, 하루 동선 전체
- (서버는 IP를 저장하지 않음. 호출 제한에만 잠깐 사용)

**동의**
- 첫 실행에서 **분명하게 선택**: [기록 보내서 Getset 함께 키우기] / [안 보낼래요] — 같은 크기의 버튼. 설정에서 언제든 변경.
- **개인정보처리방침 페이지** 신설(공개 전 필수, 광고 심사에도 필요).

**서버 구조 (Vercel Functions + 저장소)**
- `POST /api/obs` — 기록 받기. 범위 검사(0~120분 등), 호출 제한.
- `GET /api/stats?places=...` — 장소별 집계(중앙값·건수). **5건 이상일 때만** 내려줌(소수 기록으로 특정 방지).
- 집계 방식: 장소×구간별 **1분 단위 개수표(히스토그램)** 로 저장 → 중앙값 계산이 가볍고 원본 기록을 오래 보관할 필요가 없음.
- 저장소: **Upstash Redis**(Vercel 마켓플레이스, 무료 한도 내 시작) 추천 — 개수표 누적에 적합하고 관리가 거의 없음.
- 관리 페이지에서 "모두의 기록 기준 지하 주차장 도착 평균 11분(230건)"을 보고 **기본값에 반영** 가능.
- ⚠️ 이 서버 기능 첫 배포 = **Vercel Pro 구독 시점**(§2).

### 6-4. 이동 시간 학습
- 자동차는 카카오모빌리티 실측(서버 함수). 도보·자전거·대중교통은 카카오맵 경로 조회(각 하루 1,000건 무료, 2026-07-21 이후 활성화 앱 대상) 사용 검토 + 추정 폴백.
- 실제 이동 기록으로 "어림 계수"를 보정(모두의 기록에도 비율만 보냄).

## 7. 편의 기능 (모두 v1)

### 7-1. 식사 제안
- 일정이 **점심(11:30~13:30)** 또는 **저녁(17:30~19:30)** 을 지나가는데 음식점·집 들르기가 없으면 결과 화면에 카드:
  > "점심시간이 끼어 있어요." [근처 식당 찾기] [집에서 먹기] [시간만 비워두기] [괜찮아요]
- **근처 식당 찾기**: 그 시간대에 있을 곳 근처 음식점을 카카오에서 찾아 바로 추가(원하는 시간 12:00으로).
- **집에서 먹기**: 집 들르기(원하는 시간 12:00, 50분)로 추가.
- **시간만 비워두기**: 장소 없이 "식사 50분"을 그 자리에 넣음.
- 식사 시간대·길이는 관리 페이지에서 조절.

### 7-2. 영업시간·휴무 규칙
- 카카오는 영업시간을 주지 않으므로 **장소 종류별 보통 규칙**(관리 페이지에서 조절):
  - 은행 평일 09:00~16:00, 주말 휴무 / 관공서 평일 09:00~18:00 / 우체국 평일 09:00~18:00
  - 병원 평일 09:00~18:00·토 09:00~13:00, 점심 휴진 12:30~13:30 / 대형마트 10:00~22:00(의무휴업일 안내) / 백화점 10:30~20:00
- 계산: 문 열기 전이면 기다렸다 시작, 문 닫는 시간은 "그 전에 끝냄"으로 취급. 결과에 "보통 영업시간 기준"이라고 표시.
- 장소마다 **[이 곳 영업시간 고치기]** 또는 **[시간 상관없어요]** 로 끌 수 있음(사용자가 고친 값은 기기에 저장).
- 경고 예: "토요일엔 은행이 쉬어요", "병원 점심 휴진(12:30~13:30)과 겹쳐요".

### 7-3. 여유 설정 (넉넉하게 / 보통 / 딱 맞게)
- 넉넉하게: 이동 +15%, 볼일마다 +5분 / 보통: 이동 +5% / 딱 맞게: 그대로. 첫 실행에서 고르고 설정에서 변경.

### 7-4. 집 들르기 자동 제안
- 비는 시간(예약·원하는 시간 전 대기)이 **집 왕복 + 30분 이상**이면:
  > "치과 예약까지 2시간 비어요. 집에 다녀와도 50분 쉴 수 있어요." [집 들르기 넣기]
- 마트 다음 일정이 1시간 넘게 남으면: "장 본 걸 집에 두고 올까요?" [집 들르기 넣기]
- 누르면 집 들르기를 넣고 바로 다시 계산.

### 7-5. 늦어도 출발 시각 (역산)
- 예약·문 닫는 시간이 있으면 **"늦어도 오전 9:40엔 출발해야 해요"** 를 요약에 표시(그보다 늦으면 하나라도 못 지킴).

### 7-6. 마트는 마지막 제안
- 대형마트·동네마트 뒤에 다른 볼일이 있으면: "장 본 걸 들고 다니지 않게 마트를 마지막으로 할까요?" [마지막으로].

### 7-7. 캘린더에 넣기
- 시간표를 `.ics` 파일로 → 구글·삼성 캘린더에 한 번에 등록, **출발 10분 전 알림** 포함. (서버 불필요, 앱 알림보다 확실)

### 7-8. 시간표 공유
- 카톡 등으로 "오늘 일정: 9:00 출발 → 은행 → 구청 → 치과(1:30) → 3:07 끝" 텍스트 공유.

### 7-9. 루틴 저장
- "토요일 장보기"처럼 자주 하는 볼일 묶음을 저장 → 다른 날짜에 한 번에 불러오기.

### 7-10. 남은 일정 다시 짜기 (v2 → v1)
- 진행 모드에서 예정보다 늦어지면 "예정보다 12분 늦어요" 표시 + [남은 일정 다시 짜기] → 지금 시각·현재 위치에서 남은 볼일로 재계산.

## 8. 첫 실행 (정보 입력) — 신규
3~4화면, 모두 건너뛰기 가능(나중에 설정에서).

1. **집**: 현재 위치 또는 검색 → **집 주차**: 필로티(1층) / 야외 / 지하·건물 / 기계식 / 길가 / 차 없음 → (지하·건물이면) "엘리베이터 타요?" 예/아니요
2. **자주 가는 곳(선택)**: 회사·아이 학교·자주 가는 마트 등 → 각각 주차 종류, 몇 층·엘리베이터 여부(→ ③ 건물 안 시간에 반영)
3. **평소 이동수단** + **여유 성향**(넉넉하게/보통/딱 맞게)
4. **모두의 기록 동의**(§6-3)

등록한 곳은 **"내 장소"** 로 저장 → 검색 시 맨 위에 뜨고, 주차·건물 정보가 계산에 바로 쓰인다.

## 9. 추천 엔진 (v1.1 반영)

- 순서 계산: 8곳 이하 **전부 계산**(이어서 계산 + 가지치기, 8곳 약 0.16초), 9~12곳 근사(정답 대비 0분 차이 검증), 13곳 이상 제한.
- 목표: ① 예약·문 닫는 시간·영업시간 지킴 ② 가장 빨리 끝남 ③ 원하는 시간에 가깝게(10분까지 허용, 넘으면 약한 손해) ④ 이동 적게.
- "이동이 가장 적은 안"은 **아끼는 이동의 2배(최소 10분) 이내로만 늦어질 때** 함께 보여줌.
- 못 지키면 경고 + 대안("N분 일찍 출발하면 돼요", "OO를 다른 날로 미루면 돼요"). 예약 시각이 출발보다 이른 경우는 "예약 시간을 확인해 주세요".
- 검증: 무작위 300가지 일정에서 "전부 따져본 정답"과 100% 일치(단위 테스트 649개).

## 11. 관리 페이지 (`/getset/admin/`) — 신규

검색 노출 안 함, 메인에서 링크 없음. (간단한 접근 비밀번호 — 보안이라기보다 실수 방지용. 이 페이지는 값을 "파일로 만들" 뿐이고 사이트를 직접 바꾸지 않으므로 위험이 낮음)

### 11-1. 기본값 편집
- 주차장 종류 표(단계별 분, 종류 추가: 필로티·기계식·발렛 등)
- 장소 종류 표(머무는 시간, 건물 안 시간, 보통 주차장, 붐빔, 영업시간 규칙)
- 혼잡 배수, 식사 시간대, 여유 설정, 이동 어림 계수, 원하는 시간 허용치
- **바로 미리보기**: 예시 일정의 끝나는 시각이 바뀌는 걸 즉시 확인
- **[이 폰에서만 먼저 적용]**: 업로드 전 대표 폰에서 실사용 테스트
- **변경 메모** 필드 → 값 파일 안에 이력으로 남음
- **[값 파일 내려받기]** → `getset/data/model.json` 으로 깃허브 업로드 → 배포

### 11-2. 현장 측정기 (스톱워치)
- 장소 검색으로 고르고 주차장 종류 선택 → 큰 버튼을 순서대로 누름:
  `주차장 진입` → `주차 끝` → `엘리베이터 탐`(선택) → `입구 도착` → `볼일 시작` → `볼일 끝` → `차 도착` → `출차 끝`
- 요일·시간대 자동 기록. 측정 목록·주차장 종류별 평균 표시 → **[기본값에 반영]**.
- 측정 기록 파일로 내보내기(CSV). (모두의 기록 서버가 생기면 "관리자 실측"으로 함께 보냄)

### 11-3. 모두의 기록 보기 (서버 기능 이후)
- 종류×주차장별 중앙값·건수, 기록 많은 장소 목록, 기본값과의 차이 → 반영 버튼.
